# Personal Portfolio Website

A responsive, personal portfolio website built from scratch using HTML5 and CSS3. This project was developed as part of Builders Day to showcase my skills, projects, and educational background.

## Features

* **Responsive Design:** Adapts seamlessly to different screen sizes using mobile media queries.


* **CSS Animations:** Includes custom `@keyframes` for smooth sliding text effects and a floating profile image.


* **Modern Layout:** Utilizes CSS Flexbox and Grid for organized, structured sections like the 4-column Skills grid and 3-column Projects grid.


* **Interactive Navigation:** Features a sticky navigation bar with smooth scrolling behavior that links directly to different sections of the page.


* **Comprehensive Sections:** Includes dedicated areas for a Hero introduction, About Me, Skills, Projects, Education, and a Contact form.



## Technologies Used

* **HTML5:** Semantic structuring of the webpage.


* **CSS3:** Custom styling, linear gradients, hover transitions, and layout management.



## Featured Projects Displayed

The portfolio specifically highlights the following personal projects:

* **Gym Routine Tracker:** An HTML/CSS webpage layout for logging daily workouts, sets, and reps.


* **Math Formulas Page:** A reference page designed to help study mathematical concepts like probability and algebra.


* **Personal Portfolio:** This exact responsive website.



## File Structure

* `main.html`: The core file containing all the HTML markup and embedded CSS styles for the entire portfolio.



## How to Run

1. Clone this repository to your local machine.
2. Ensure you have the profile image named exactly `HTML IMAGE.jpeg` in the same directory as `main.html` so the hero section renders correctly.


3. Open `main.html` in any modern web browser (e.g., Chrome, Firefox, Edge) to view the site. No server installation is required.
